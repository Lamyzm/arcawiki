# ADR-0003. 원문은 복제하지 않고 링크로 보낸다

- 상태: 채택
- 날짜: 2026-08-11

## 맥락

DB 에는 두 종류가 들어간다. 크롤링한 원문 1,000건 이상과, 내가 만든 위키 문서
20~30개. 웹에서 무엇까지 보여줄지 정해야 했다.

원문까지 전부 보여주면 커버리지가 처음부터 100% 가 되고 검색도 아카라이브보다
나아진다. 그러나 그것은 채널 사람들이 쓴 글 1,000건을 우리 사이트에 그대로
복제해 띄우는 일이 된다. 수집해서 가공에 쓰는 것과 성격이 다르다.

## 결정

웹은 **위키 문서를 보여주고, 원문은 아카라이브 링크로 보낸다.** 원문 본문을
우리 화면에 띄우지 않는다.

원문 **제목과 메타데이터는 검색 대상에 포함**한다. 데이터가 이미 DB 에 있어
비용이 없고, 아직 위키 문서를 만들지 않은 주제도 "그런 글이 있다"까지는
알 수 있게 하기 위해서다. 클릭하면 아카라이브로 나간다.

연령 게이트(451)가 걸린 글에 친구가 접근할 수 있는지는 이 프로젝트에서
다루지 않는다.

## 이유

- 남이 쓴 글을 통째로 재배포하지 않는다. 인용과 출처 표시의 범위 안에 머문다.
- 원문을 안 띄우면 성인 글 노출을 웹에서 따로 가릴 필요가 거의 없어진다.
- 우리가 더하는 값은 원문 보관이 아니라 **합성과 정리** 다. 링크로 보내도
  그 값어치는 줄지 않는다.

## 결과

- 웹 화면은 위키 문서 중심으로 단순해진다.
- 원문 본문은 DB 에 남아 있지만 오직 생성 재료로만 쓰인다.
- 아카라이브에서 글이 삭제되면 링크가 죽는다. 위키 문서 본문은 남으므로
  내용 자체는 보존되지만, 검증 경로는 끊긴다. `post_versions` 에 본문을
  남겨두는 이유가 여기에도 있다.
