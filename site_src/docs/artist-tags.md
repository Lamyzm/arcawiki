# 작가 태그 사전 — 이걸 쓰면 이렇게 나온다

> 작가 태그를 넣으면 무엇이 달라지는지, 채널 원문에 적힌 표현 그대로 옮긴 것이다.
> 지어낸 설명은 없다. 원문에 코멘트가 없는 작가는 아예 넣지 않았다.
>
> 주요 출처: 130458775 · 132727305 · 168535060 · 166985227 · 122522153 ·
> 151423873 · 154204833 · 159947900 · 180607255 · 157943050

!!! warning "모델 세대를 먼저 확인할 것"
    같은 작가라도 세대가 바뀌면 평가가 뒤집힌다.
    `jtveemo` 는 V3 에서 눈매 국밥이었다가 V4 에서 지뢰가 됐고,
    `tianliang duohe fangdongye` 는 V5 에서 가중치 0.2 만으로도 그림체를 바꿔 버린다.
    아래 표는 세대가 갈리는 경우 양쪽을 다 적어 뒀다.

## 0. 먼저 알아야 할 세 가지

프롬프트를 못 짜겠다면 이 셋만 알아도 절반은 된다.

!!! danger "⚠ ANIMA 에서는 순서가 안 먹는다 — 우리 실측"
    아래 "순서가 가중치보다 세다"는 **NAI 기준**이다. ANIMA 에서 직접 확인해 보니 성립하지 않았다.

    ![작가 태그 베이스라인 비교](img/baseline-artist.png)

    같은 시드(77123456) · ANIMA `anima-aesthetic-v1.1` · 1024×1536 · 축 하나씩만 변경.

    | | 결과 |
    |---|---|
    | **A** 작가 없음 | 밝고 평면적. 눈이 크고 단순 |
    | **B** 국밥 8명 | **눈매가 또렷해지고 음영이 깊어진다.** 작가 스택은 확실히 먹는다 |
    | **C** 같은 8명, **순서만 뒤집음** | **B 와 거의 같다** |
    | **D** 같은 8명, **전부 1.0** | **가장 어둡고 눈이 처진다.** 과한 쪽으로 간다 |

    **확인된 것** — 작가 스택은 먹고(A↔B), 가중치를 눌러 쓰는 것도 맞다(B↔D).
    **성립하지 않은 것** — 순서(B↔C).

    이유는 인코더 구조다. ANIMA 는 qwen3 LLM 이 프롬프트를 **통째로** 인코딩해 평균을 내므로
    순서 정보가 SDXL·NAI 만큼 살아남지 않는다. **ANIMA 를 쓴다면 순서 대신 가중치와 조합에 집중하면 된다.**

### 순서가 가중치보다 세다

> **앞쪽에 쓴 작가가 채색과 바디 형태를 담당하고, 뒤쪽에 쓴 작가가 얼굴, 특히 눈을 담당한다.**
> 작가 프롬이 많아질수록 이 경향이 강해진다. — 글 122522153

> 강조를 3.0 이상 줘도 잘 안 나왔는데 **단순히 위치를 바꾸니 원하는 대로 나왔다.** — 글 151423873

| 위치 | 담당 |
|---|---|
| **앞** | 몸매 · 구도 · 채색의 큰 틀 |
| 중간 | 색감 · 분위기 |
| **뒤** | **얼굴 · 눈** — 인상이 여기서 갈린다 |

### 가중치 문법

```
1.1::artist:NAME ::
```

> `{}`, `[]` 하나당 0.05 다. **제발 중괄호 쓰지 말고 직관적인 숫자 가중치를 써라.** — 글 132727305

!!! danger "이름이 숫자로 끝나면 한 칸 띄어야 한다"
    `qys3` 처럼 끝이 숫자면 **`qys3 ::`** 처럼 공백을 넣어야 한다.
    안 그러면 **그 뒤의 모든 태그에 가중치 3배가 붙는다.**

### 같은 작가를 두 번 넣는다

> 같은 작가를 높은 가중치로 때려넣는 것보다, **가중치를 분할해서 앞뒤 혹은 중간에 2번 이상 넣으면**
> 그 작가 특색이 더 잘 살아난다. — 글 159947900

## 9. 네거티브에 넣는 작가

### 고정 3인방

```
xinzoruo · milkpanda · kurukurumagical
```

V5 그림체 공유글에서 반복해서 등장한다. 공통적으로 **선 굵고 색이 납작한 개그·카툰체** 작가들이라,
네거에 넣으면 그 반대 방향(외곽선 제거, 명암·디테일 상승)으로 밀린다.

> 네거 쪽에 닮기 싫은 작가 몇을 넣으면 **"이렇게는 그리지 말라"는 명령**이 되어서
> 긍정 프롬에 넣은 작가 성향이 조금 더 뚜렷해진다. — 글 180524305 댓글

### 살색 조절 스위치

> 살색이 너무 누르렁한 경우 → **`(bb (baalbuddy):1.3)` 를 `bkub` 등으로 변경** — 글 128832358

### 반대 조언 — 안 나올 때는 걷어내라

> "단일 작가면 네거티브에 작가 들어간 거 **싹 걷어내고** 스텝 수 낮게 해봐" — 글 180530013

### 작가가 안 섞이고 한 명만 튀어나올 때

```
-3::artist collaboration ::     (강하게는 -6, -8 까지)
solo artist
```

채널 표준 관용구다. **39개 글에서 실사용**이 확인된다.

### 보너스 — `banned artist`

긍정 프롬에 넣은 A/B 실험 결과(글 113538328), 두 항목만 일관되게 재현됐다.

> **눈에서 AI 특유의 물거북 향이 빠지고 사람이 그린 것에 가까워진다.
> 텍스쳐가 유광에서 무광에 가까워진다.**
