# arcawiki

아카라이브 AI그림채널(`/b/aiart`)의 게시글 6,400여 건을 읽어서, **아무것도 모르는 사람이
로컬 이미지 생성을 직접 돌릴 수 있는 수준까지 올라오도록** 주제별 위키로 압축한다.

채널에는 쓸 만한 정보가 많지만 6,000개 글을 다 읽을 수는 없다. 그래서 글을 읽는 것은
파이프라인이 하고, 사람은 결과 문서만 읽는다.

## 왜 이렇게 만들었나

이 채널 글의 값은 **본문이 아니라 댓글에 있는 경우가 많다.** 본문이 틀린 설정을 적어
놓고 댓글이 실측으로 고친 사례가 지금까지 140건 넘게 나왔다. 그래서 이 위키는 요약이
아니라 **주장 단위로 쪼개서 서로 부딪히게** 만들어져 있다.

```
posts  ──▶  knowledge_cards  ──▶  claims  ──▶  wiki_entries
글 1개        글 1개당 카드 1개      재사용되는     문서에 실리는
+ 댓글        (기법·설정·시점)       주장 단위      항목
                                      ▲
                        card_claims ──┘
                        support / contradict / context  + 인용문(필수)
```

- 한 주장이 여러 글에서 반복되면 `claims` 행 하나를 **재사용**한다. 그래서 "이 말은
  근거가 12건" / "이 말은 근거가 1건인데 반박이 3건" 이 자동으로 드러난다.
- 댓글이 본문을 부정하면 `contradict` 로 연결한다. **다만 댓글이라고 다 맞지는 않는다** —
  근거가 실측인지(시드·설정 고정하고 한 변수만 바꿈), 재실험인지, 원문 확인인지, 글쓴이가
  수긍했는지, 아니면 그냥 인상인지를 함께 기록한다. 근거 없는 단언은 지우지 않고
  **근거가 없다고 밝혀서** 싣는다.
- 낡은 자료(2023년 SD1.5·코랩 시절)도 버리지 않는다. 첫 문장에 시점을 밝히고
  `usefulness` 를 낮춘다. 1년 넘은 항목은 문서에 ⚠ 표시가 붙는다.

## 현재 규모

| | |
|---|---|
| 수집한 원문 | 6,439건 |
| 읽은 원문 | 2,185건 (34%) |
| 주장 | 3,152개 |
| 카드–주장 링크 | 4,843개 |
| 문서 / 항목 | 20개 / 720개 |

34%가 낮아 보이지만 읽는 순서를 우선순위로 정렬해 두었다. 입문·설치·용어·오류 글을
먼저 비우고, 남은 것은 대부분 대회 공지와 결과물 자랑이다.

## 구조

```
crawler.py            arca.live → posts/<id>.json      (원본. 이후 읽기 전용)
ingest.py             posts/ → Postgres posts 테이블
pipeline.py           우선순위 매겨 work_queue 채우기
  (Claude Code)       큐를 집어 카드 추출 · 카드를 주장으로 통합 · 항목 작성
export.py             DB → site_src/docs/*.md + mkdocs.yml
  (MkDocs Material)   → 정적 사이트
```

수집·적재·큐 채우기는 Docker 로 자동화되어 있고, **판단이 필요한 일(무엇이 기법이고
무엇이 잡담인지, 어느 근거가 무거운지)만 Claude Code 세션에 맡긴다.** 경계를 왜 이렇게
그었는지는 `docs/adr/0006-automation-boundary.md` 에 있다.

설계 결정 기록은 `docs/adr/` 에 6건 있다. 특히 `0003-link-out-instead-of-reproducing.md` —
원문을 복제하지 않고 링크로 내보내는 원칙.

## 실행

```bash
cp .env.example .env          # POSTGRES_PASSWORD 채우기
docker compose up -d          # db · pipeline · wiki · tunnel
python ingest.py              # posts/ 를 DB로
python export.py              # DB를 site_src/ 로
```

`docker compose` 는 MkDocs 사이트를 띄우고, Cloudflare 터널로 외부에 노출한다.
`CF_TUNNEL_TOKEN` 을 넣으면 고정 주소를, 비워 두면 매번 바뀌는 임시 주소를 쓴다.

## 수집에 관하여

- `robots.txt` 를 지킨다. `/b/aiart` 는 Allow. 금지된 `/u/`(유저 페이지), `/b/my`,
  `*/edit`, `*/delete` 는 건드리지 않는다.
- 요청 간격 1.5초, 로그인 세션을 쓸 때는 2.5초로 늘린다.
- HTTP 451 로 막힌 글은 **건너뛰고 기록만 남긴다.** 우회하지 않는다.
- 성인 등급 글은 비로그인 상태에서 목록에조차 나오지 않아서, 그 범위를 보려면
  브라우저에 이미 로그인된 세션의 쿠키를 재사용한다. **ID/PW 는 다루지 않는다.**
  쿠키는 `cookie.txt` 에 두고 `.gitignore` 로 커밋을 막는다.

## 라이선스와 출처

- **코드**(`*.py`, `db/`, `docker-compose.yml` 등)는 MIT. `LICENSE` 참조.
- **`site_src/docs/` 의 문서 내용은 다르다.** 아카라이브 이용자들이 쓴 글에서
  나온 것이고, 저작권은 각 작성자에게 있다. 이 위키는 원문을 복제하지 않고
  짧게 인용하면서 **모든 항목마다 원문 링크를 붙인다**(항목당 근거 목록 + 문서 하단
  출처 목록). 자기 글을 빼고 싶은 작성자는 이슈를 열어 주면 지운다.
- 채널 내용의 상당 부분이 성인 대상이다. 문서는 기법 전달 가능성만을 기준으로
  정리했고 내용을 순화하지 않았다. `HIDE_ADULT=true` 로 해당 문서를 기본 숨김 처리할 수 있다.
